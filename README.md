# Amoha Homes

Marketing site for Amoha Group — premium townships and plots on Bathinda's Ring Road.

Five static pages: the home page plus one for each project (Amoha Gardens, Amoha Leaf,
Amoha Roots, and the fourth site in planning). No build step — open `index.html`, or serve
the folder with any static server.

Motion is GSAP + ScrollTrigger with Lenis smooth scroll. The bougainvillea are real
transparent video: VP9 `.webm` everywhere, HEVC-with-alpha `.mov` twins for WebKit.

This is a client preview. `robots.txt` disallows crawlers so it is shareable but not indexed.
