# Amoha Group

Website for Amoha Group, Bathinda: the home page and one page for each project.

| Page | |
| --- | --- |
| `index.html` | Home |
| `amoha-gardens.html` | Amoha Gardens |
| `amoha-leaf.html` | Amoha Leaf |
| `amoha-roots.html` | Amoha Roots |
| `amoha-next.html` | The upcoming project |

A static site with no build step: serve the folder with any web server.

- `css/` design tokens, base styles, section layouts, motion states and the brand layer
- `js/` start-up, components, scroll engine and reveals, scenes, the bougainvillea sprays and the falling petals
- `js/vendor/` GSAP, ScrollTrigger, SplitText and CustomEase (GreenSock Standard licence), Lenis (MIT)
- `assets/` images, video and fonts. Fraunces, Manrope and Aboreto are used under the SIL Open Font
  License 1.1 (`assets/fonts/OFL.txt`)

Designed and developed by Jatin Dhir.
